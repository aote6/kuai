Kuai Vision

Kuai's goal is not to provide dozens of blocks.

Kuai's goal is: any capability can be registered as a Block.

The number of Blocks is theoretically unlimited.

Extreme examples of what a Block could be:

  AI writing code          -> one Block
  Controlling a drone      -> one Block
  Making an HTTP request   -> one Block
  Playing music            -> one Block
  Sending a text message   -> one Block
  Training a model         -> one Block

Each Block is just a contract (.block) + a Python function.
The engine doesn't care what the Block does. It only cares that
the contract is honored.

This means Kuai can grow from file management to anything.
The framework doesn't change. Only the Blocks change.
